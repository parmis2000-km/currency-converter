# مبدل ارز

یک اپلیکیشن تحت وب برای تبدیل دلار به ریال و ریال به دلار، توسعه‌ یافته با React.

## قابلیت‌ ها

- تبدیل دلار به ریال و ریال به دلار
- دریافت مبلغ و نرخ تبدیل از کاربر
- اعتبارسنجی ورودی‌ ها و نمایش خطاهای مرتبط با استفاده از Zod
- نمایش قالب‌ بندی‌ شده ی اعداد به فارسی

## تکنولوژی‌ ها

- React
- JavaScript
- Tailwind CSS
- tailwind-merge
- Zod

## هدف پروژه

تمرین توسعه رابط کاربری با React، مدیریت ورودی‌ های کاربر، اعتبارسنجی داده‌ ها و پیاده‌ سازی منطق تبدیل ارز.
